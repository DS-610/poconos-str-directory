# Provider Recruitment Playbook

Goal: get 30-50 real Poconos STR service providers listed on the directory in the next 2 weeks. Every listing they claim or you add is a future $75/mo customer.

## Where to find providers (2 hours of work)

1. Facebook Groups - search "Poconos Airbnb host", "Poconos property management",
   "Poconos cleaning", "Monroe County small business". Look for:
   - Cleaning crews advertising "turnover cleaning"
   - Handymen posting about STR work
   - Vendors in host group recommendation threads
2. Google Maps - search "cleaning service Stroudsburg", "handyman Tannersville",
   "HVAC East Stroudsburg", "plumber Milford", "lawn care Hawley". Call or visit websites.
3. Airbnb/VRBO service listings - some hosts list their trusted vendors in listing descriptions.
4. Property managers - the 3-5 biggest local STR property managers each know 10-20 vendors.
5. Local bulletin boards - hardware stores, laundromats, real estate offices in
   Stroudsburg, Jim Thorpe, Milford, Hawley.

## Fastest workflow

1. Start with 20 cleaning crews + 10 handymen (the plan's target).
2. Find their name, phone, service area. That's all you need for a listing.
3. Send them the DM below. Claim a FREE listing in 30 seconds.
4. If they don't respond in 3 days, add them yourself via the CSV import
   (name + phone + town is enough; I'll fill in the details).
5. Text or call any provider with a 570 area code - they pick up.

Day 3: Comment on their public post with the link in-group (one time only).

are looking for [category] right now. Grab it: [site URL]/auth/signup"
